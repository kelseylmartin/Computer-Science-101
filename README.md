# 🎓 Interactive CS & AI Mastery Course

A single-file, interactive web application designed to simulate a rigorous, university-level Computer Science and Artificial Intelligence curriculum.

This tool serves as both a course syllabus and an interactive learning environment, allowing users to read deep-dive lectures on complex CS topics and immediately apply them using a built-in terminal emulator.

# ✨ Features

Interactive Pseudo-Terminal: Practice real Bash, Python, and JavaScript commands directly in the browser. The terminal evaluates user input against expected Regular Expressions to grade homework assignments.

Persistent Progress Tracking: Uses browser localStorage to save your completed modules. You won't lose your progress if you close or refresh the page.

No Backend Required: 100% Client-side. Built with Vanilla JavaScript and HTML, meaning it can be hosted anywhere for free.

Modern UI/UX: Styled with Tailwind CSS, featuring dark mode aesthetics, syntax highlighting fonts (Fira Code), and fluid animations.

# 📚 Course Curriculum

The syllabus is designed to take a student from operating system fundamentals to deploying distributed AI architectures.

CS 101: Operating Systems & The Unix Environment (Linux) - Standard streams, IPC, redirection, logging, and POSIX permissions.

CS 102: Programming Paradigms (Python) - Memory management, pointers, dynamic typing, and garbage collection.

CS 201: Distributed Version Control (Git) - Directed Acyclic Graphs (DAGs), staging indexing, and the three-tree architecture.

AI 301: Applied Machine Learning Architectures (Hugging Face) - Transformer architecture, tokenization, embeddings, and NLP pipelines.

CV 302: Computer Vision & Convolutional Networks (Ultralytics) - CNNs vs. Transformers, YOLO paradigms, and executing training loops for object detection.

CS 401: API Architecture & Asynchronous I/O (Web Wrappers) - RESTful principles, the JavaScript Event Loop, and building full-stack AI wrappers.

CS 402: Cloud Infrastructure & Containerization - Provisioning compute, IaaS, SSH cryptography, and containerizing with Docker.
